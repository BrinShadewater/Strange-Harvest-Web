# Contributing

## Local Setup

```shell
npm install
npm run dev
```

Before opening a pull request:

```shell
npm run build
```

## Pull Requests

- Keep changes focused on one public-facing concern.
- Include screenshots or preview links for visual changes.
- Call out SEO, analytics, consent, geolocation, or watch-link changes explicitly.
- Avoid replacing the site's voice with generic marketing copy.

## Content Notes

Film titles, streaming availability, review badges, structured data, and regional availability can become stale. Include the source or reason for changes when touching those areas.
