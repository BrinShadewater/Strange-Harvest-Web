# Project Brief

## Purpose

Strange Harvest Web is the official web presence for the feature film **Strange Harvest**. It supports discovery, credibility, and conversion: people should be able to understand the film, watch the trailer, find where to stream or buy it, read press/review material, and move through the film's world without the site feeling like a generic promo page.

## Audience

- Viewers looking for trailers, synopsis, cast, reviews, and watch options
- Press, festival, and distribution contacts checking official material
- Search engines and AI answer surfaces reading structured metadata
- International visitors who need localized paths and availability cues

## Product Principles

- Official, not sterile.
- Search-friendly, not content-farmed.
- Atmospheric, but fast and readable.
- Clear conversion paths for watch and merch actions.
- Metadata is part of the product, not afterthought polish.

## High-Risk Areas

- Watch availability and region-specific links can become stale.
- Reviews, ratings, and platform badges should reflect current source material.
- Cookie consent and analytics changes can create compliance issues.
- Large image additions can harm performance if not optimized.
- Film copy should stay consistent with official positioning.
