# Security

## Reporting

Please do not open public issues for security-sensitive findings.

Contact the maintainer privately through the GitHub profile associated with this repository and include:

- What you found
- Steps to reproduce
- Affected URL, route, or file
- Suggested fix, if known

## Areas To Treat Carefully

- Cookie consent and analytics scripts
- Geolocation endpoints
- Shopify or merch integrations
- External watch links and embeds
- Static HTML pages under `public/`

## Maintenance

Run dependency and build checks before deployment. Keep environment-specific secrets outside the repository.
